# OPCSpace 原型中心

本目录同时保存历史冻结原型和当前产品评审原型。全部内容只用于需求、视觉、交互和信息联动评审，不代表正式功能已经实现。

- `admin/`：管理端冻结静态原型。
- `mini/`：小程序冻结静态原型。
- `review-v0.3/`：依据 PRD v0.3 生成的双端功能联动评审原型，包含可维护的 HTML/CSS/JS、统一约定和页面架构。
- `index.html`：当前评审版与历史冻结版的统一入口。

`admin/` 与 `mini/` 是旧版构建产物，禁止在压缩后的 JavaScript bundle 中继续开发。`review-v0.3/` 是可维护的产品评审资产，但仍不是正式业务源码。

正式工程边界：

- 管理前端：`../apps/admin-web/`
- 小程序：`../apps/mini-app/`
- 后端：`../services/backend/`

需要预览时，将本目录作为站点根目录交给任意标准静态 HTTP 服务。仓库不再维护平台专用的启动和停止脚本。
