# OPCSpace 冻结原型

本目录保存管理端与小程序的静态效果页，只作为产品需求、视觉设计和交互盘点的证据。

- `admin/`：管理端冻结静态原型。
- `mini/`：小程序冻结静态原型。
- `index.html`：双端原型统一入口。

这些文件是构建产物，不是可维护的正式源码，禁止在压缩后的 JavaScript bundle 中继续开发业务功能。

正式工程边界：

- 管理前端：`../apps/admin-web/`
- 小程序：`../apps/mini-app/`
- 后端：`../services/backend/`

需要预览时，将本目录作为站点根目录交给任意标准静态 HTTP 服务。仓库不再维护平台专用的启动和停止脚本。
