# OPCSpace v0.3 双端原型自查整改要求（2026-08-29）

以下是对本原型按《产品设计自查表》和《七大易用原则量化标准（总体设计规范 V1.1）》全量自查后的整改候选，共 17 条。当前阶段先由产品评审确认口径，再逐条整改；不要把未确认的业务规则写成既定能力。

## 页面：总入口及跨页面

1. 【Z-标记-03/05/06】请确认本次 v0.3 是否作为新的评审基线；若仍需与冻结旧原型逐项比较，需在改动原位保留旧内容并补新增、修改、删除标识。
2. 【Z-首页-05】若采用增量评审方式，为双端入口补“上次改动版本”徽标；若采用新基线方式，记录豁免理由。
3. 【Z-整体-02/04】在研发实施设计中补历史数据迁移、在途单据和旧链接兼容策略。

## 页面：小程序表单与附件页面

1. 【Z-表单-02/04/06】按业务线补手机号唯一性、时间格式、下拉数据源及字段级联/清空规则。
2. 【Z-上传-02/03】补附件大小、文件名上限、重复文件和上传失败反馈规则。
3. 【P-08】确认长文本统一上限采用 150 还是 300 字；确认后全局统一，并为长文本提供计数反馈。
4. 【T-02】确认移动端弹窗是否遵循平台化“取消”关闭；若要求双端完全一致，为确认弹窗补右上角关闭入口。

## 页面：管理端列表与侧边导航

1. 【T-03/C-06】在默认按业务时间倒序的表格中显示当前降序状态。
2. 【C-13】增加一条超长主题静态样例，展示省略和查看完整内容的方式。
3. 【R-08/P-10】选择一个代表性列表，展示“有权限但业务条件不满足”的置灰动作和原因提示。
4. 【E-10】补管理端侧边栏收起、展开及收起后的临时查看方式。
5. 【D-02】为管理端空结果补统一的品牌化空状态图形。

## 跨页面（一致性与业务规则）

1. 【T-05/D-03】正式 UI 阶段把当前文字图标替换为同一套产品图标库。
2. 【Z-接口-01】闭环确认后补双端接口字段、幂等键、状态版本、回调及审计契约。
3. 【Z-配置-03】补配置变更对存量业务和在途流程的影响规则。
4. 【Z-整体-07/09】补异常分类、空状态处置、存储周期、分页阈值和容量指标。
5. 【Z-说明-04】对确认进入闭环设计的业务补逻辑表、边界用例和静态示例。

## 整改完成要求

- 先确认“新评审基线/增量差异评审”、长文本上限、移动端弹窗关闭方式、关键指标与高频操作五项口径。
- 逐条回报已改内容或不改理由，不顺手扩展未确认业务。
- 完成后仅复查本清单的 ⚠️ 与 ❓ 项，并更新三份自查文件。
