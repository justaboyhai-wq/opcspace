# OPCSpace v0.3 双端原型页面架构

## 1. 管理端

| 角色域 | 页面集合 | 关联编号 |
|---|---|---|
| 共用工作台 | 经营总览、我的待办 | ADM-01-01、ADM-01-02 |
| 招商 | 企业档案、合同台账、续租退租、装修入驻 | ADM-05-01 至 ADM-05-04 |
| 财务 | 账单、收款对账、发票、电费账户、空调加时、押金、企业对账单 | ADM-04-01 至 ADM-04-07 |
| 运营 | 报修工单、投诉、环境服务、空间资源、空间预约、停车业务、访客通行、客服队列 | ADM-02-01 至 ADM-02-04、ADM-06-01 至 ADM-06-04、ADM-09-02 |
| 内容 | 公告、活动、企业服务、AI 订阅、产品反馈、Banner | ADM-07-01 至 ADM-07-06 |
| 超级管理员 | 小程序账号、隐私请求、统一审批、AI 运营、自动化、后台账号、角色权限、消息规则、操作审计、数据质量、配置发布、充值可见态 | ADM-08、ADM-09-01/03/04、ADM-10 |

管理端采用数据驱动单页原型，每个菜单项有独立路由键、列表、详情和与小程序的信息联动说明。工程设备与施工巡检不建立路由。

## 3. 双端演示主线

1. 企业成员在小程序提交报修，管理端运营工作台出现待受理工单，处理进度返回小程序。
2. 企业管理员创建访客邀请，管理端审批并展示门禁授权，通行证和闸机核销事件返回小程序。
3. 企业管理员查看账单并登记缴费，财务端完成匹配入账，缴费结果和发票状态返回小程序。
4. 企业成员申请空间，运营端处理预约冲突，预约凭证和取消结果返回小程序。
5. 企业管理员发起续租或装修申请，招商端查看材料和审批信息，节点进度返回小程序。
6. 内容人员发布公告、活动和服务，目标企业在小程序首页、通知和对应频道看到内容。
