## 追踪维护规则

1. 功能进入迭代前补齐稳定 API、权限码、表/事件和测试 ID。
2. 原型页面新增按钮时，先判断为展示、查询、命令、审批、异步任务或外部动作，再进入 PRD。
3. 一个业务命令必须同时追踪正常路径、异常路径、权限负向、并发/幂等和审计测试。
4. 状态从“基座待建/规划”变为“已实现”时，必须附上可重复构建、测试和端到端验收证据。
