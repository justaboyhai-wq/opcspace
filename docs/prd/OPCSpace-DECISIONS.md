# OPCSpace PRD 待决策事项

> 本清单只记录会影响产品规则、范围或验收的未决问题。未确认前不得由研发自行假设为正式制度。
> 当前范围和角色以 [OPCSpace PRD](./OPCSpace-PRD.md) 为准；已排除的工程设备、物业巡检、维保告警不得重新作为待确认项混入。

## P0：进入逐功能闭环评审前必须确认

| ID | 主题 | 需要确认的结论 | 建议责任人 | 未确认时默认处理 |
|---|---|---|---|---|
| P0-01 | 管理端角色与责任 | 招商、财务、运营、内容、超级管理员的人员范围；跨角色待办、审批和数据权限 | 项目负责人+各业务负责人 | 只确认角色族，不预设具体岗位和自动分派 |
| P0-02 | 项目与空间数据 | 和盛大厦楼宇/楼层/空间编码、企业占用关系、数据责任人 | 物业+招商 | 使用脱敏开发种子，不作为验收数据 |
| P0-03 | 报修分类与 SLA | 分类、优先级、服务时间、首次响应/到场/完工时限、升级人 | 运营负责人 | 只记录时间，不据此自动处罚或承诺 |
| P0-04 | 工单撤回/挂起/重开 | 可操作窗口、理由、SLA 是否停表、用户重开期限 | 运营负责人 | 高风险分支人工处理并完整留痕 |
| P0-05 | 验收与自动关闭 | 谁可代验收、几次提醒、多久自动关闭、低分如何回访 | 物业负责人 | 不自动关闭，由客服人工确认 |
| P0-06 | 成员唯一性 | 同一手机号能否加入多个企业、企业切换、离职后历史可见性 | 物业+法务/隐私 | 允许多关系但每次选择当前企业；历史最小可见 |
| P0-07 | 激活与换绑 | 激活信息发送渠道、手机号验证、微信换绑/解绑和遗失处置 | 产品+安全 | 只允许管理员重发；换绑必须人工核验 |
| P0-08 | 附件规则 | 图片/视频类型、数量、大小、保留期、敏感内容和病毒扫描 | 产品+安全+运维 | 仅图片、小数量、私有桶、扫描通过后绑定 |
| P0-09 | 个人信息 | 手机号/姓名/微信身份的收集告知、用途、留存、导出和删除流程 | 法务/隐私负责人 | 最小收集、默认脱敏、禁止批量导出 |
| P0-10 | 闭环评审主体 | 每个 `FC-*` 的业务负责人、评审人、结论记录方式和冻结标准 | 项目负责人 | 未指定负责人时只保留功能事实，不进入流程定稿 |
| P0-11 | 小程序入口开放 | 入口全园区统一开放，还是按项目、企业合同、套餐和角色差异化开放 | 产品+招商+运营 | 只展示当前原型入口，不承诺企业差异化 |

## P1：各业务进入需求定稿前确认

| ID | 主题 | 需要确认的结论 | 建议责任人 |
|---|---|---|---|
| P1-01 | 投诉匿名 | 是否允许匿名、哪些角色可解密、法定留存和升级规则 | 物业+法务 |
| P1-02 | 空间预约 | 资源目录、开放时段、审批人、取消/爽约、收费与凭证规则 | 运营负责人 |
| P1-03 | 访客与通行硬件 | 最小必要信息、审批条件、访问区域、二维码、门禁授权、闸机核销、离线和人工放行 | 运营+安保+法务+技术 |
| P1-04 | 内容发布 | 公告/活动受众、复核、紧急发布、撤回、评论与报名规则 | 内容负责人 |
| P1-05 | 消息渠道 | 站内信、微信订阅消息、短信的使用场景、模板与用户同意 | 运营+法务 |
| P1-06 | 客服与投诉关联 | 会话转工单、投诉转工单、重复问题合并和责任归属 | 客服主管 |
| P1-07 | 数据指标 | 服务量、SLA、满意度、一次解决率的口径和业务基线 | 运营+数据 |
| P1-08 | 软件运行指标 | 并发、P95、可用性、RPO/RTO、接口和任务失败告警门槛 | 技术+运维 |
| P1-09 | 环境服务履约 | 保洁、绿化、消杀是物业自营还是第三方；报价锁定、加价、取消、验收和收费规则 | 运营+财务 |
| P1-10 | 企业服务代办 | 服务目录、顾问组织、SLA、材料、线下合同、第三方办理和最终交付物标准 | 招商+企业服务负责人 |
| P1-11 | 租赁业务流程 | 续租、入驻、装修、退租的真实审批链、材料清单、押金、交接和关闭条件 | 招商+运营+财务 |

## P2：进入外部集成与财务详细设计前确认

| ID | 主题 | 需要确认的结论 | 建议责任人 |
|---|---|---|---|
| P2-01 | 租赁权威系统 | OPCSpace 是合同权威源还是既有系统的业务前台；合同版本、付款计划和交接数据由谁负责 | 招商+财务 |
| P2-02 | 财务权威系统 | 费项、账单、会计日期、减免、对账和关账由谁负责 | 财务负责人 |
| P2-03 | 支付与发票 | 渠道/服务商、商户号、退款权限、可开票来源、红冲/重开、电子文件交付和沙箱协议 | 财务+法务+技术 |
| P2-04 | 访客门禁集成 | 门禁/闸机厂商、授权协议、回调、离线策略、人工补偿和 SLA | 运营+安保+技术 |
| P2-05 | 停车业务边界 | 车辆、月租、优惠、临停缴费和记录的数据来源；不包含停车硬件控制 | 运营+财务 |
| P2-06 | 电费业务边界 | 账户、账单、充值、回单和入账的数据来源；不包含电表设备管理和实时抄表 | 财务+技术 |
| P2-07 | AI 范围 | 仅问答或允许动作草稿；AI 商品是否真实售卖；知识源、供应商、计费、席位、额度、数据出境、内容安全和风控负责人 | 产品+安全+业务 |
| P2-08 | 多项目扩展 | 同一物业多项目的组织、数据权限、品牌和配置继承方式 | 管理层+产品 |
